* **Опис роботи:**
* Проєкт являє собою десктопний додаток (Windows Forms) мовою C++, розроблений у MS Visual Studio для табулювання математичної функції та візуалізації її графіка.Основні етапи та функціонал роботи:Введення параметрів: Зчитування кількості кроків ($k$) від користувача та автоматичне обчислення кроку $h$ для заданого проміжку $[-1.6; 1.6]$.Обчислення: Циклічний розрахунок значень варіанта функції $y = \frac{\sqrt{\vert{}x^2 - 5x - 6\vert{}}}{\cos x}$ з використанням методів System::Math (Sqrt, Abs, Cos).Табулювання: Форматування та виведення результатів у вигляді текстової таблиці (пар значень $x$ та $y$) за допомогою компонента ListBox.Візуалізація: Побудова графіка функції на базі обчислених точок за допомогою компонента Chart (тип графіка — плавна лінія Spline із маркерами Circle).Керування та очищення: Реалізація окремих кнопок для обчислень, малювання графіка та швидкого очищення всіх вхідних і вихідних даних (полів, списку та графіка).
